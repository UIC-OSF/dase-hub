Signing in

  1. Open dase.uic.edu/submit-stats (or /admin).
  2. Enter the DASE team passcode and press Continue. It's the same passcode for both pages, and the browser remembers it for 30 days.
If the browser asks for a username and password first, that's the site's preview login (dase.uic.edu is still in preview). It's separate from the team passcode — use the preview login Chris shared, then the passcode.

Update a number

  1. On Submit Stats, scroll to the category (for example Deliver Comprehensive Accessibility Training). Each row shows the metric, what it counts, and the value currently on the dashboard.
  2. Press Update on the metric you want to change.
  3. Type the new number. Only the number changes — the words around it ("Total: … People") stay the same, unless you open Change the wording around the number to edit them (for example Hours → Sessions).
  4. Optionally rename it (Metric name), reword What this counts, or set a Goal — the green bar then tracks progress toward the goal on its own (page 7).
  5. Add your name and press Save Update. The dashboard updates immediately — no sync, no delay.

Auto-synced numbers: rename or set a goal

Metrics marked Auto-synced (Equalify scanning, users, Iris conversions, the ADA Title II card) get their value and definition from Equalify every 6 hours, so there's nothing to type in. You can still rename them or give them a goal: press Rename / goal on the row.

Add a new metric

Every category on Submit Stats ends with + Add a metric to this objective. Use it when you start tracking something new.

  1. Press + Add a metric to this objective under the right category.
  2. Metric name — what appears on the dashboard, e.g. Annual Workshop Attendees.
  3. Value — the full badge text, e.g. Total: 47 People or Count: 12. Keep the pattern label: number unit; next time you'll only have to type the number.
  4. Goal (optional) — e.g. 1500; the bar tracks progress toward it automatically.
  5. What this counts — one plain sentence. Directors read these, so say where the number comes from.
  6. Your name, then Add Metric.
Need a whole new category? Add it on the Admin page first (Add Objective — title and date range), then come back to Submit Stats to add its metrics.

Show, hide, reorder and delete

The Dashboard layout section of dase.uic.edu/admin lists every category (card) and its metrics.

  • Hide or show a metric — untick or tick the checkbox next to its name. Hidden metrics keep their values (and keep syncing), they just don't appear publicly. Submit Stats marks them Hidden.
  • Hide or show a whole category — the Shown checkbox on the right of the card. A category with no visible metrics also disappears on its own.
  • Rename a category or change its date range — press Edit name & dates under the category title, change the text, press Save.
  • Reorder — the ▲ ▼ buttons move a card up or down the dashboard. Metrics inside a card appear in the order they were added; message Chris if you need them in a different order.
  • Add a category — the Add Objective form at the bottom: a title and a date range (for example Jan 2026 - {today}, see page 7).
  • Delete — the × on a metric or the Delete button on a card removes it permanently (you'll be asked to confirm). To take something off the dashboard temporarily, hide it instead.

Date ranges and goals

Date ranges

The line under each category title (for example Jan 2025 - Oct 2026) is the category's date range. Change it any time on the Admin page with Edit name & dates. It accepts the token {today}, which always shows the current month — so Jan 2025 - {today} reads "Jan 2025 - Oct 2026" now and updates itself every month. Use a fixed range (Feb 2026 - June 2026) for a project with an end date.

Goals and the progress bar

Give any metric a Goal on its Update form (or on Rename / goal for auto-synced ones). Once a goal is set:

  • the green bar shows current value ÷ goal automatically — 1,017 attendees against a goal of 1,500 fills the bar to 68% — and keeps itself up to date as the number changes;
  • the dashboard shows a line under the metric: Goal: 1,500 · 68% there;
  • the hand-set Progress bar fill no longer applies. Clear the Goal box to go back to setting the bar by hand.
Pick goals you'd be happy to see on the public dashboard — the goal number is visible to everyone, not just the team.

Numbers that update themselves

Four cards are fed by integrations rather than by hand: Equalify Scanning, Equalify Users & Audits, Equalify Iris, and ADA Title II Readiness. Each of their metrics shows Synced from Equalify (or Iris) and when it last refreshed.

  • They refresh automatically every 6 hours.
  • To refresh right now (for example before a meeting), press Sync Now on the Admin page's Integrations cards.
  • Their definitions are fixed by the integration so they always match Equalify's own Account › Statistics page.
  • You can still rename them, give them a goal, hide any of them, or move the cards, exactly like manual metrics.

Good habits

  • Update manual numbers on a regular day each month, and always add your name. The dashboard shows totals, not history, so keep your own monthly log (the DAS spreadsheet works); the Admin page's Recent manual submissions list records who changed what, and when.
  • Keep "What this counts" in plain language — it's what directors see.
